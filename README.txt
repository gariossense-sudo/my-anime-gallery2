# My Anime Gallery V2

Tombol **Tambah Foto** membuat penambahan foto jauh lebih mudah.

Isi:
- Kategori: Waifu / Anime / Penghormatan
- Nama
- Umur
- Catatan
- Foto

PENTING:
Versi ini dibuat tanpa R2/backend. Foto yang ditambahkan melalui tombol **Tambah Foto**
disimpan di localStorage browser pada perangkat tersebut. Jadi foto tidak otomatis
masuk ke GitHub dan tidak otomatis muncul di perangkat lain.

Ini sengaja dipakai sebagai versi sederhana tanpa biaya penyimpanan cloud.
Untuk sinkronisasi antar-HP/laptop, kita perlu menambahkan storage cloud/backend.
